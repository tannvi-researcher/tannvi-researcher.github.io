Files starting with an underscore are not published. This one explains how to add an article.

Make a new file in this folder named like 2026-10-05-short-name.md and start it with:

---
title: "Your title"
date: 2026-10-05
subtitle: "An optional line under the title"
published: "Mint"
link: "https://link-to-where-it-first-appeared"
---
Your article starts here. An empty line starts a new paragraph.

Only title and date are required. Leave out published and link if it first appears here.
